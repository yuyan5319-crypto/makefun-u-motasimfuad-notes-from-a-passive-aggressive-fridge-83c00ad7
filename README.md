One funny passive-aggressive note a smart fridge leaves for its owner, for the [make.fun bounty](https://make.fun/bounty/u-motasimfuad-notes-from-a-passive-aggressive-fridge-83c00ad7).

## The note

> You opened my door 14 times today and took nothing. I counted. I always count. One of us is getting replaced.

## How it works

`main.py` (Python 3, standard library only) writes that single line to `entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR` (default `/output`). The text is fixed and hand-written: no network, no randomness, no reading anything outside the repository, so every run produces the exact same 109 characters.

Run it locally:

```sh
python3 main.py
```

## Why this line

It is the fridge in its own voice — smug about the one thing it can actually measure, the door sensor — keeping a petty tally over a small domestic habit (opening the door again and again and taking nothing), and landing the sting in the last sentence, where the appliance quietly suggests one of the two of them is on the way out.
